# Async+ Durable Awaiters: True Resume Architecture

**Status**: Design Document - R&D
**Version**: 1.0 (December 2025)
**Prerequisites**: Read `Async+.md` first

---

## Executive Summary

Current Async+ checkpoints state machine **fields** but cannot serialize **awaiters**. On restore, workflows re-run from the beginning with restored field values. This works for idempotent operations but causes duplicate execution for non-idempotent ones.

This document proposes **Durable Awaiters**: awaiters backed by Orleans grains that persist their results. On restore, awaiters are rehydrated from grain state, enabling true resume at the exact await point without re-execution.

## Problem Analysis

### Current Async+ Behavior

```csharp
[Persistable]
public async Task<int> MyWorkflow(int x)
{
    var a = await Step1(x);      // Checkpoint 0: saves {x}
    var b = await Step2(a);      // Checkpoint 1: saves {x, a}
    return a + b;
}
```

**State machine generated by Roslyn:**
```csharp
struct <MyWorkflow>d__0 : IAsyncStateMachine
{
    public int <>1__state;           // State number
    public int x;                     // Parameter (hoisted)
    public int <a>5__1;              // Local 'a' (hoisted)
    public int <b>5__2;              // Local 'b' (hoisted)
    public TaskAwaiter<int> <>u__1;  // Awaiter for Step1
    public TaskAwaiter<int> <>u__2;  // Awaiter for Step2
    public AsyncTaskMethodBuilder<int> <>t__builder;

    public void MoveNext()
    {
        switch (<>1__state)
        {
            case 0: goto Label_Await0;
            case 1: goto Label_Await1;
        }

        // State -1: Start
        <>u__1 = Step1(x).GetAwaiter();
        if (!<>u__1.IsCompleted)
        {
            <>1__state = 0;
            // CHECKPOINT 0 injected here
            <>t__builder.AwaitUnsafeOnCompleted(ref <>u__1, ref this);
            return;
        }

    Label_Await0:
        <a>5__1 = <>u__1.GetResult();  // ← PROBLEM: awaiter must exist!

        <>u__2 = Step2(<a>5__1).GetAwaiter();
        if (!<>u__2.IsCompleted)
        {
            <>1__state = 1;
            // CHECKPOINT 1 injected here
            <>t__builder.AwaitUnsafeOnCompleted(ref <>u__2, ref this);
            return;
        }

    Label_Await1:
        <b>5__2 = <>u__2.GetResult();  // ← PROBLEM: awaiter must exist!

        <>t__builder.SetResult(<a>5__1 + <b>5__2);
    }
}
```

### Why Awaiters Can't Be Serialized

`TaskAwaiter<T>` holds:
- Reference to the underlying `Task<T>`
- Internal state for continuation management
- Execution context references

These are **runtime constructs** tied to the current process. They cannot be serialized and restored in a different process/time.

### Current Restore Behavior

```
CHECKPOINT 1 saved: { x=7, a=14, <>1__state=1 }
                    (awaiters NOT saved)

ON RESTORE:
1. Fields restored: x=7, a=14
2. State reset to -1 (NOT to 1)
3. MoveNext() called
4. switch(-1) → starts from beginning
5. Step1(x) called AGAIN
6. Checkpoint 0 saved AGAIN
7. a = awaiter.GetResult() → a=14 (or different if not idempotent!)
8. Step2(a) called
9. ... continues
```

### The Consequence

| Operation Type | On Replay | Problem |
|---------------|-----------|---------|
| Pure computation | Re-computes, same result | Wasted work |
| Database read | Re-reads | Potentially stale data |
| HTTP GET | Re-fetches | Potentially different response |
| HTTP POST | Re-posts | **Duplicate action!** |
| Payment | Re-charges | **Duplicate charge!** |
| Email send | Re-sends | **Duplicate email!** |

## Proposed Solution

### Core Idea: Durable Awaiters

Replace `TaskAwaiter<T>` with `DurableAwaiter<T>` that:
1. Is **serializable** (just grain key + context ID)
2. Stores results in **Orleans grains**
3. Can be **rehydrated** on restore
4. Returns **cached results** instead of re-executing

### Conceptual Flow

```
FIRST EXECUTION:
━━━━━━━━━━━━━━━━
var a = await Step1(x);
    │
    ├── DurableAwaiter created with:
    │   ├── GrainKey: "workflow-123/await/0"
    │   └── ContextId: "workflow-123"
    │
    ├── Step1(x) executes → returns 14
    │
    ├── Result stored in grain:
    │   IAwaitResultGrain["workflow-123/await/0"].SetResult(14)
    │
    └── Checkpoint saves: { x=7, a=14, awaiterKeys=["workflow-123/await/0"] }


ON RESTORE:
━━━━━━━━━━━
1. Load checkpoint: { x=7, a=14, awaiterKeys=["workflow-123/await/0"] }

2. Rehydrate awaiters:
   foreach (key in awaiterKeys)
       awaiter[key] = new DurableAwaiter(key, contextId)
       // Grain already has result from first execution

3. Set <>1__state = 1 (resume at checkpoint state, NOT -1)

4. MoveNext() called
   switch(1) → goto Label_Await1

5. At Label_Await1:
   <a>5__1 = <>u__1.GetResult()
           │
           └── DurableAwaiter.GetResult()
               │
               └── grain.GetResultAsync() → returns 14 (cached!)

6. Continue from Step2, no re-execution of Step1!
```

## Component Design

### 1. `DurableAwaiter<T>`

**Location**: `src/NewOrleans/src/NewOrleans.AsyncPlus/Awaiters/DurableAwaiter.cs`

```csharp
using System.Runtime.CompilerServices;

namespace NewOrleans.AsyncPlus.Awaiters;

/// <summary>
/// A serializable awaiter that stores results in Orleans grains.
/// Enables true resume from await points without re-execution.
/// </summary>
[Serializable]
public struct DurableAwaiter<T> : ICriticalNotifyCompletion
{
    /// <summary>
    /// Grain key for the result storage grain.
    /// Format: "{workflowId}/await/{awaitIndex}"
    /// </summary>
    public string GrainKey { get; init; }

    /// <summary>
    /// Workflow instance ID for context isolation.
    /// </summary>
    public string ContextId { get; init; }

    /// <summary>
    /// Index of this await point (0, 1, 2, ...).
    /// </summary>
    public int AwaitIndex { get; init; }

    /// <summary>
    /// The underlying task (only set during first execution, not after restore).
    /// </summary>
    [NonSerialized]
    private Task<T>? _underlyingTask;

    /// <summary>
    /// Grain factory reference (injected via AsyncPersistenceContext).
    /// </summary>
    [NonSerialized]
    private IGrainFactory? _grainFactory;

    /// <summary>
    /// Creates a new durable awaiter wrapping an existing task.
    /// Called during first execution.
    /// </summary>
    public static DurableAwaiter<T> Create(
        Task<T> task,
        string workflowId,
        int awaitIndex,
        IGrainFactory grainFactory)
    {
        var grainKey = $"{workflowId}/await/{awaitIndex}";

        return new DurableAwaiter<T>
        {
            GrainKey = grainKey,
            ContextId = workflowId,
            AwaitIndex = awaitIndex,
            _underlyingTask = task,
            _grainFactory = grainFactory
        };
    }

    /// <summary>
    /// Rehydrates a durable awaiter from serialized state.
    /// Called during restore.
    /// </summary>
    public static DurableAwaiter<T> Rehydrate(
        string grainKey,
        string contextId,
        int awaitIndex,
        IGrainFactory grainFactory)
    {
        return new DurableAwaiter<T>
        {
            GrainKey = grainKey,
            ContextId = contextId,
            AwaitIndex = awaitIndex,
            _underlyingTask = null,  // No underlying task on restore
            _grainFactory = grainFactory
        };
    }

    /// <summary>
    /// Checks if the await result is available.
    /// </summary>
    public bool IsCompleted
    {
        get
        {
            // If we have an underlying task (first execution), check it
            if (_underlyingTask != null)
            {
                return _underlyingTask.IsCompleted;
            }

            // Otherwise, check the grain (restore path)
            var grain = GetResultGrain();
            return grain.HasResultAsync().GetAwaiter().GetResult();
        }
    }

    /// <summary>
    /// Gets the result, either from the underlying task or from the grain.
    /// </summary>
    public T GetResult()
    {
        var grain = GetResultGrain();

        // If we have an underlying task that completed, store result in grain
        if (_underlyingTask != null)
        {
            if (_underlyingTask.IsFaulted)
            {
                grain.SetExceptionAsync(_underlyingTask.Exception!.InnerException!).GetAwaiter().GetResult();
                throw _underlyingTask.Exception.InnerException!;
            }

            if (_underlyingTask.IsCanceled)
            {
                var cancelEx = new TaskCanceledException(_underlyingTask);
                grain.SetExceptionAsync(cancelEx).GetAwaiter().GetResult();
                throw cancelEx;
            }

            var result = _underlyingTask.Result;
            grain.SetResultAsync(result).GetAwaiter().GetResult();
            return result;
        }

        // No underlying task - we're restoring, get from grain
        var state = grain.GetStateAsync().GetAwaiter().GetResult();

        if (state.HasException)
        {
            throw state.Exception!;
        }

        return state.Result!;
    }

    /// <summary>
    /// Registers continuation for async completion.
    /// </summary>
    public void OnCompleted(Action continuation)
    {
        UnsafeOnCompleted(continuation);
    }

    /// <summary>
    /// Registers continuation without capturing execution context.
    /// </summary>
    public void UnsafeOnCompleted(Action continuation)
    {
        if (_underlyingTask != null)
        {
            // First execution: use underlying task's continuation
            _underlyingTask.ConfigureAwait(false).GetAwaiter().UnsafeOnCompleted(continuation);
        }
        else
        {
            // Restore path: result should already be available
            // If not, we need to poll or use grain-based signaling
            Task.Run(async () =>
            {
                var grain = GetResultGrain();
                while (!await grain.HasResultAsync())
                {
                    await Task.Delay(100);
                }
                continuation();
            });
        }
    }

    private IAwaitResultGrain<T> GetResultGrain()
    {
        if (_grainFactory == null)
        {
            _grainFactory = DurableAwaiterContext.Current?.GrainFactory
                ?? throw new InvalidOperationException(
                    "DurableAwaiter requires grain factory. " +
                    "Ensure DurableAwaiterContext.Current is set.");
        }

        return _grainFactory.GetGrain<IAwaitResultGrain<T>>(GrainKey);
    }
}
```

```csharp
namespace NewOrleans.AsyncPlus;

/// <summary>
/// Grain interface for storing await results durably.
/// One grain per await point per workflow instance.
/// </summary>
/// <typeparam name="T">The result type of the await.</typeparam>
public interface IAwaitResultGrain<T> : IGrainWithStringKey
{
    /// <summary>
    /// Checks if a result (or exception) has been stored.
    /// </summary>
    Task<bool> HasResultAsync();

    /// <summary>
    /// Gets the full state including result or exception.
    /// </summary>
    Task<AwaitResultState<T>> GetStateAsync();

    /// <summary>
    /// Stores a successful result.
    /// </summary>
    Task SetResultAsync(T result);

    /// <summary>
    /// Stores an exception (for faulted tasks).
    /// </summary>
    Task SetExceptionAsync(Exception exception);

    /// <summary>
    /// Clears the stored result (for cleanup or retry).
    /// </summary>
    Task ClearAsync();

    /// <summary>
    /// Gets metadata about this await point.
    /// </summary>
    Task<AwaitResultMetadata> GetMetadataAsync();
}

/// <summary>
/// State of an await result grain.
/// </summary>
[GenerateSerializer]
public sealed class AwaitResultState<T>
{
    [Id(0)] public bool HasResult { get; set; }
    [Id(1)] public T? Result { get; set; }
    [Id(2)] public bool HasException { get; set; }
    [Id(3)] public Exception? Exception { get; set; }
    [Id(4)] public DateTime? CompletedAtUtc { get; set; }
}

/// <summary>
/// Metadata about an await point.
/// </summary>
[GenerateSerializer]
public sealed class AwaitResultMetadata
{
    [Id(0)] public string WorkflowId { get; set; } = "";
    [Id(1)] public int AwaitIndex { get; set; }
    [Id(2)] public string ResultTypeName { get; set; } = "";
    [Id(3)] public DateTime CreatedAtUtc { get; set; }
}
```

### 3. `AwaitResultGrain<T>` Implementation

**Location**: `src/NewOrleans/src/NewOrleans.AsyncPlus/Grains/AwaitResultGrain.cs`

```csharp
using Microsoft.Extensions.Logging;
using Orleans.Runtime;

namespace NewOrleans.AsyncPlus.Grains;

/// <summary>
/// Grain implementation for storing await results.
/// Uses Orleans persistent state for durability.
/// </summary>
public class AwaitResultGrain<T> : Grain, IAwaitResultGrain<T>
{
    private readonly IPersistentState<AwaitResultGrainState<T>> _state;
    private readonly ILogger<AwaitResultGrain<T>> _logger;

    public AwaitResultGrain(
        [PersistentState("awaitResult", "AsyncPlusStorage")]
        IPersistentState<AwaitResultGrainState<T>> state,
        ILogger<AwaitResultGrain<T>> logger)
    {
        _state = state;
        _logger = logger;
    }

    public Task<bool> HasResultAsync()
    {
        return Task.FromResult(_state.State.HasResult || _state.State.HasException);
    }

    public Task<AwaitResultState<T>> GetStateAsync()
    {
        return Task.FromResult(new AwaitResultState<T>
        {
            HasResult = _state.State.HasResult,
            Result = _state.State.Result,
            HasException = _state.State.HasException,
            Exception = _state.State.Exception,
            CompletedAtUtc = _state.State.CompletedAtUtc
        });
    }

    public async Task SetResultAsync(T result)
    {
        if (_state.State.HasResult || _state.State.HasException)
        {
            _logger.LogWarning(
                "Await result grain {GrainKey} already has result, ignoring duplicate SetResult",
                this.GetPrimaryKeyString());
            return;
        }

        _state.State.HasResult = true;
        _state.State.Result = result;
        _state.State.CompletedAtUtc = DateTime.UtcNow;

        await _state.WriteStateAsync();

        _logger.LogDebug(
            "Stored result for await {GrainKey}: {ResultType}",
            this.GetPrimaryKeyString(), typeof(T).Name);
    }

    public async Task SetExceptionAsync(Exception exception)
    {
        if (_state.State.HasResult || _state.State.HasException)
        {
            _logger.LogWarning(
                "Await result grain {GrainKey} already has result, ignoring SetException",
                this.GetPrimaryKeyString());
            return;
        }

        _state.State.HasException = true;
        _state.State.Exception = exception;
        _state.State.CompletedAtUtc = DateTime.UtcNow;

        await _state.WriteStateAsync();

        _logger.LogDebug(
            "Stored exception for await {GrainKey}: {ExceptionType}",
            this.GetPrimaryKeyString(), exception.GetType().Name);
    }

    public async Task ClearAsync()
    {
        await _state.ClearStateAsync();

        _state.State.HasResult = false;
        _state.State.Result = default;
        _state.State.HasException = false;
        _state.State.Exception = null;
        _state.State.CompletedAtUtc = null;

        _logger.LogDebug("Cleared await result grain {GrainKey}", this.GetPrimaryKeyString());
    }

    public Task<AwaitResultMetadata> GetMetadataAsync()
    {
        var grainKey = this.GetPrimaryKeyString();
        var parts = grainKey.Split("/await/");

        return Task.FromResult(new AwaitResultMetadata
        {
            WorkflowId = parts.Length > 0 ? parts[0] : "",
            AwaitIndex = parts.Length > 1 && int.TryParse(parts[1], out var idx) ? idx : -1,
            ResultTypeName = typeof(T).AssemblyQualifiedName ?? typeof(T).Name,
            CreatedAtUtc = _state.State.CreatedAtUtc
        });
    }
}

/// <summary>
/// Persistent state for await result grain.
/// </summary>
[GenerateSerializer]
public sealed class AwaitResultGrainState<T>
{
    [Id(0)] public bool HasResult { get; set; }
    [Id(1)] public T? Result { get; set; }
    [Id(2)] public bool HasException { get; set; }
    [Id(3)] public Exception? Exception { get; set; }
    [Id(4)] public DateTime? CompletedAtUtc { get; set; }
    [Id(5)] public DateTime CreatedAtUtc { get; set; } = DateTime.UtcNow;
}
```

### 4. `DurableAwaiterContext`

**Location**: `src/NewOrleans/src/NewOrleans.AsyncPlus/Awaiters/DurableAwaiterContext.cs`

```csharp
namespace NewOrleans.AsyncPlus.Awaiters;

/// <summary>
/// Ambient context for durable awaiters.
/// Provides access to grain factory and workflow ID without method signature changes.
/// </summary>
public static class DurableAwaiterContext
{
    private static readonly AsyncLocal<DurableAwaiterContextData?> _current = new();

    /// <summary>
    /// Gets the current context for this async flow.
    /// </summary>
    public static DurableAwaiterContextData? Current => _current.Value;

    /// <summary>
    /// Sets the context for durable awaiters.
    /// </summary>
    public static IDisposable SetCurrent(IGrainFactory grainFactory, string workflowId)
    {
        var previous = _current.Value;
        _current.Value = new DurableAwaiterContextData(grainFactory, workflowId);
        return new ContextScope(previous);
    }

    private sealed class ContextScope : IDisposable
    {
        private readonly DurableAwaiterContextData? _previous;
        private bool _disposed;

        public ContextScope(DurableAwaiterContextData? previous)
        {
            _previous = previous;
        }

        public void Dispose()
        {
            if (!_disposed)
            {
                _current.Value = _previous;
                _disposed = true;
            }
        }
    }
}

/// <summary>
/// Context data for durable awaiters.
/// </summary>
public sealed class DurableAwaiterContextData
{
    public IGrainFactory GrainFactory { get; }
    public string WorkflowId { get; }
    public int NextAwaitIndex { get; private set; }

    public DurableAwaiterContextData(IGrainFactory grainFactory, string workflowId)
    {
        GrainFactory = grainFactory;
        WorkflowId = workflowId;
    }

    /// <summary>
    /// Gets the next await index and increments the counter.
    /// </summary>
    public int GetNextAwaitIndex() => NextAwaitIndex++;

    /// <summary>
    /// Resets the await index counter (used on restore to replay from correct position).
    /// </summary>
    public void ResetAwaitIndex(int startIndex) => NextAwaitIndex = startIndex;
}
```

### New Attribute

```csharp
/// <summary>
/// Marks an async method for durable persistence with true resume.
/// Uses DurableAwaiters backed by Orleans grains.
/// </summary>
[AttributeUsage(AttributeTargets.Method, AllowMultiple = false)]
public class DurablePersistableAttribute : Attribute
```

### Modified Code Generation

**Current (re-run model):**
```csharp
// Generated MoveNext
<>u__1 = Step1(x).GetAwaiter();  // TaskAwaiter
if (!<>u__1.IsCompleted) { ... checkpoint, suspend ... }
Label_Await0:
<a>5__1 = <>u__1.GetResult();
```

**New (durable awaiter model):**
```csharp
// Generated MoveNext

<>u__1 = DurableAwaiter<int>.Create(Step1(x), __workflowId, __awaitIndex0, __grainFactory);
if (!<>u__1.IsCompleted) { ... checkpoint with await keys, suspend ... }
Label_Await0:
<a>5__1 = <>u__1.GetResult();  // Gets from grain if restored
```

```csharp
/// <summary>
/// Scenario DA1: Basic Durable Awaiter
///
/// PURPOSE: Verify that DurableAwaiters correctly store and restore results,
/// enabling true resume without re-execution.
///
/// TEST FLOW:
/// 1. Start workflow with [DurablePersistable]
/// 2. Execute Step1, result stored in grain
/// 3. Checkpoint at await Step2
/// 4. Simulate crash (stop silo)
/// 5. Restart silo
/// 6. Resume workflow
/// 7. Verify Step1 was NOT re-executed (result came from grain)
/// 8. Verify Step2 executes and completes
///
/// KEY VALIDATIONS:
/// - Step1 execution count = 1 (not 2)
/// - Result from restored awaiter matches original
/// - Workflow completes correctly
/// </summary>
public static class DurableAwaiterBasic
{
    private static int _step1ExecutionCount = 0;

    [DurablePersistable]
    public static async Task<int> TestWorkflow(int input)
    {
        // Step1: Increment counter and compute
        var a = await Step1(input);      // Should execute once, result stored

        // Step2: Another computation
        var b = await Step2(a);          // Executes after restore

        return a + b;
    }

    private static async Task<int> Step1(int x)
    {
        Interlocked.Increment(ref _step1ExecutionCount);
        await Task.Delay(100);
        return x * 2;
    }

    private static async Task<int> Step2(int x)
    {
        await Task.Delay(100);
        return x + 10;
    }

    public static async Task RunAsync()
    {
        // ... silo setup, run workflow, crash, restore, verify ...

        Assert(_step1ExecutionCount == 1,
            $"Step1 should execute once, but executed {_step1ExecutionCount} times");
    }
}
```

## Migration Strategy

### Approach: Parallel Attributes

Keep both `[Persistable]` (re-run model) and `[DurablePersistable]` (true resume):

| Attribute | Behavior | Use Case |
|-----------|----------|----------|
| `[Persistable]` | Checkpoint fields, re-run on restore | Idempotent workflows, simpler |
| `[DurablePersistable]` | Checkpoint + await grains, true resume | Non-idempotent, critical workflows |

### Migration Path

1. **Existing workflows**: Keep using `[Persistable]`
2. **New critical workflows**: Use `[DurablePersistable]`
3. **Migrate gradually**: Convert workflows that need true resume

## Open Questions

### 1. Generic Grain Registration

Orleans requires explicit generic grain registration. How to handle `IAwaitResultGrain<T>` for arbitrary T?

**Options:**
- Use `object` and serialize/deserialize
- Register common types explicitly
- Use source generator to detect types

### 2. Awaiter Field Serialization

Current checkpoint serializes state machine fields but skips awaiters. With durable awaiters, we need to serialize their grain keys.

**Options:**
- Serialize `DurableAwaiter<T>` fields (GrainKey, AwaitIndex)
- Store await keys separately in checkpoint
- Hybrid: store metadata separately, reconstruct awaiters

### 3. Cleanup Strategy

When a workflow completes, its await result grains should be cleaned up.

**Options:**
- Explicit cleanup on Complete()
- TTL-based expiration in RavenDB
- Lazy cleanup on workflow restart

### 4. Non-Task Awaitables

Some await expressions use custom awaitables (ValueTask, ConfiguredTaskAwaitable).

**Options:**
- Only support Task<T> initially
- Create DurableValueAwaiter<T>
- Wrap all awaitables in Task<T>

## Summary

This document describes the Durable Awaiter architecture for Async+, enabling true workflow resume without re-execution. The key insight is replacing `TaskAwaiter<T>` with `DurableAwaiter<T>` backed by Orleans grains, allowing awaiter state to be serialized and rehydrated.

**Implementation effort estimate:**
- Core infrastructure: ~2-3 days
- Roslyn modifications: ~3-4 days
- Testing and debugging: ~2-3 days
- Total: ~7-10 days

**Risk areas:**
- Generic grain registration complexity
- Roslyn modification complexity
- Edge cases with custom awaitables
